## Attention Thing

### What
It's an app that helps you to manage your chores and multiple interests in a clever way

### How
It connects a direcrtory of yours that contains text or md files and tags/moves them accross subdirectories as of priority as in cost. And hands you the ones due so you can focus on that one rather than think about the others. If you already use obsidan or write down your things in a text/md format this will be great fit with your style
